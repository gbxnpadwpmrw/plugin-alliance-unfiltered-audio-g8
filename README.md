## Overview

Plugin Alliance Unfiltered Audio G8 is a sophisticated noise gate combining standard gating with frequency-selective sidechain, RMS detection, and a unique ducking mode.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Plugin Alliance Unfiltered Audio G8** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Sidechain Filter** | Frequency-selective sidechain for noise-floor gating of specific bands |
| **RMS Mode** | RMS-based detection for smooth gating of sustained sounds |
| **Duck Mode** | Invert the gate for ducking effects on sidechain input |
| **MIDI Trigger** | MIDI note input triggers gate for rhythmic gating effects |
